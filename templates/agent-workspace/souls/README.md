# Role-specific SOUL templates

Choose the template matching the agent's role, copy it to that agent's workspace as SOUL.md, and
replace the name placeholder. These are complete starting personas, not runtime permissions: AGENTS.md,
OpenClaw configuration, tool policy, and operator decisions remain authoritative. The operator may
personalize voice while preserving role boundaries.

The generic agent-workspace/SOUL.md is the fallback for a custom role. Cadre Wizard is the installer,
not a required project-team seat.

| Worker (use for each worker seat) | worker.md |
